# Third Party Licenses

KQLBridge leverages the following open-source libraries. We are grateful to the authors and communities for their excellent contributions to database and compiler engineering:

## 1. Lark (Parsing Frontend)
- **License:** MIT
- **Role:** Lexing and AST parsing for standard KQL syntax definitions.

## 2. DuckDB (Verification Engine Backend)
- **License:** MIT
- **Role:** High-performance in-memory execution backend and oracle validation for compiled SQL targets.

## 3. SQLGlot (Dialect and Structural Checks)
- **License:** MIT
- **Role:** Canonical query representation and query verification.

## 4. Pandas (Data Processing Interface)
- **License:** BSD 3-Clause
- **Role:** Reference dataframes in DuckDB local execution sweeps.
